## How the classes are used

- **verified_correction:** provable without the video, from the workbook or the dataset manifest. The value is written into the working workbook (green).
- **rule_based_proposal:** follows from an approved rule applied to what the annotator recorded. The value is written (yellow), and a video check is recommended.
- **needs_video_review:** only the video can answer, so **no value is proposed**; the cell is marked (orange). Description wording only selects records for review here; it never supplies a value.
- **informational:** recorded, no change.
- Rows proposed for removal stay in the sheet, struck through, with a review flag; new records are appended with the next free id. Nothing is renumbered.
- Possible out-of-taxonomy clips carry the `OUT_OF_TAXONOMY_CANDIDATE` flag; their type stays one of the five.
